# Flappy Bird

This is a Flappy Bird game project created using Unity.

## Features
- Simple and addictive gameplay.
- Procedurally generated obstacles.
- Score tracking system.
- Restart functionality.

## Requirements
- Unity 6000.0.40f1
- Basic understanding of Unity and C#.

## How to Play
1. Clone or download the project to your local machine.
2. Open the project in Unity.
3. Press the Play button in the Unity Editor to start the game.
4. Tap or click to make the bird flap and avoid obstacles.

## Project Structure
- **Assets/**: Contains all game assets, scripts, and prefabs.
- **Scenes/**: Includes the main game scene.
- **Scripts/**: Contains C# scripts for game mechanics.
